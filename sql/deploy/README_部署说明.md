# HR 系统数据库部署说明

## 目录说明

- `01_全新环境_一键初始化.sql`
  - 适用于全新数据库（推荐演示环境使用）
  - 包含：若依基础库 + Quartz + HR 模块 + 字典 + 演示员工数据 + 文本乱码修复

- `02_仅HR模块初始化.sql`
  - 适用于已有若依基础库（`sys_*` 已存在）
  - 包含：HR 模块结构与升级脚本、字典、文本乱码修复

- `03_演示数据导入.sql`
  - 只导入 HR 演示员工与修复文本
  - 适合已完成 HR 初始化后补数据

## 执行顺序

### 场景 A：新电脑全新部署（推荐）
1. 新建数据库（字符集 `utf8mb4`，排序规则建议 `utf8mb4_general_ci`）。
2. 执行 `01_全新环境_一键初始化.sql`。

### 场景 B：已有若依库，补 HR 功能
1. 执行 `02_仅HR模块初始化.sql`。
2. 如需演示数据，再执行 `03_演示数据导入.sql`。

## 注意事项

- 请使用 MySQL 5.7+ / 8.0。
- 执行前建议先备份。
- 脚本编码已统一为 `UTF-8 (无 BOM)`，避免中文乱码。
- 演示员工默认密码沿用脚本内规则；`admin` 账户仍可直接登录。
